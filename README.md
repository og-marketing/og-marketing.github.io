# OG Marketing — Video Portfolio Website

> High-retention video editing, motion design, and algorithmic visual storytelling engineered to build authority and convert viewers into loyal customers.

## Overview
A luxury brutalist video production and digital marketing portfolio website for **OG Marketing**. Designed for high visual impact with curated short-form and commercial deliverables.

## Key Features
- **Luxury Brutalist Aesthetic**: High-contrast black & white design with Montserrat and Inter Black typography.
- **In-Site Embedded Video Player**: Plays video deliverables directly inside an interactive in-site modal with sound, avoiding third-party clutter.
- **Curated Category Filters**:
  - Clothing & Product Shoots
  - Interior & Real Estate
  - Promotion Reels
  - Car & Commercial Launches
- **Mobile First**: Side-by-side CTA buttons ("Chat with Us" & "OG Marketing"), full responsiveness across all screen sizes.
- **Instant Connect**: WhatsApp direct link, quick email inquiry, and Telegram contact.

## Tech Stack
- **Frontend**: HTML5, Vanilla CSS3, Modern JavaScript
- **Integration**: YouTube Embed API (in-site playback with unmuted audio)
- **Deployment**: Static site ready for GitHub Pages, Vercel, or Netlify
